# 847 PS3: Bathroom Tissue Demand

This repository contains the PS 3 project files, including raw data, papers, archived analyses, Python code, and estimation results. The original repository README is preserved.

Start with `PROJECT_STATUS_v2.md` and `Analysis/mixed_logit_v4/REPORT_zh.md`. Mixed-logit results are exploratory: six specifications converged and two were rejected; model/instrument restrictions and integration accuracy still require work.

Large files use Git LFS. Install Git LFS before cloning, or run `git lfs install` followed by `git lfs pull` after cloning. Files below 10 MiB remain in ordinary Git.
