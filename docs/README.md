# Collaboration hub

This folder is the shared memory for Yifan, Wenhan, and agents working from either account. A fresh agent should be able to continue using the repository alone; chat access is not assumed.

## Start each session

1. Read [STATUS.md](STATUS.md) for current research and engineering state.
2. Read [WORKPLAN.md](WORKPLAN.md) and the latest [handoff](handoffs/README.md).
3. Follow [COLLABORATION.md](COLLABORATION.md); consult [SETUP.md](SETUP.md) before running code.
4. Use [decisions/](decisions/README.md) for accepted choices and [validation/](validation/README.md) for evidence.

| Document or folder | Role | Update policy |
|---|---|---|
| STATUS.md | Current facts, limits, and next priorities | Update in place; keep concise |
| WORKPLAN.md | Work IDs, ownership, dependencies, status | Update in place; do not silently claim another person's work |
| COLLABORATION.md | Shared workflow and result-preservation rules | Change when the workflow changes |
| SETUP.md | Reproducible environment and safe commands | Change with tooling |
| handoffs/ | Dated session records and the original Chinese baseline | Add a new file per meaningful round |
| decisions/ | Durable choices and superseding decisions | Add numbered records; retain the history |
| validation/ | Dated checks, environment, and limitations | Add evidence for each consequential change |
| templates/ | Handoff, decision, and validation starting points | Reuse for future rounds |
| history/ | Superseded original entry notes | Preserve as historical records |

The old handoff filenames remain as navigation redirects. Research reports stay beside their analysis versions; this hub links to them rather than copying every result.
