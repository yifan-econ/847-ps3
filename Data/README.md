# Source data

Dominick/ contains original movement data, customer counts, store demographics, the codebook, and legacy SAS-format copies.

- wtti.csv: toilet-paper movement data.
- ccount.dta: customer counts for weekly market size.
- demo.dta: store-area demographics and pricing-zone identifiers.
- Dominicks-Manual-and-Codebook_KiltsCenter.pdf: variable definitions.

Current analyses use CSV/Stata inputs and the archived cleaned panel. The UPC table is at Archive/ps3_v1/inputs/upctti.csv, relative to the repository root. Preserve original data, including zero records. Prepared data belong in the relevant analysis version.

Several files use Git LFS; see [setup](../docs/SETUP.md).
